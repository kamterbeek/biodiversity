# Biodiversity Intelligence Platform

The Biodiversity Intelligence Platform This project is designed to demonstrate modern analytics engineering, semantic modeling, and data platform architecture while supporting conservation research and biodiversity education.

---

## This Project

Global biodiversity data is scattered across hundreds of organizations.

Researchers often spend more time collecting data than analyzing the data.

This platform combines biodiversity, climate, wildfire, habitat, and conservation datasets into a single analytics platform that supports:

- Conservation research
- Environmental education
- Biodiversity monitoring
- AI-assisted analytics
- Data-driven decision making

---

## Features

- Live biodiversity data ingestion
- Automated ETL pipelines
- Analytics engineering with dbt
- Semantic modeling with LookML
- Airflow orchestration
- Interactive dashboards
- AI-powered natural language exploration
- Data quality testing
- Automated documentation
